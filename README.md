# ForgePlan/slopocop-humanizer-en — English Text De-Slop Skill

Removes AI slop from **English** text and rewrites it in a specific human voice — banned phrases, em-dash ban, copula-avoidance fixes, varied rhythm.

> **Attribution.** This is a mirror of **slop-humanizer by [humanizer-tools](https://github.com/humanizer-tools/slop-humanizer)** (MIT). Full credit to the original
> author — ForgePlan only re-publishes it for `npx skills add` convenience as part of the
> [slopocop](https://github.com/ForgePlan/marketplace) anti-slop family. The original license is
> preserved; no authorship is claimed.

## Install

```bash
# Global (recommended):
npx skills add ForgePlan/slopocop-humanizer-en -g

# Project-only:
npx skills add ForgePlan/slopocop-humanizer-en
```

Installs as `slop-humanizer`.
